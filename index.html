下面匯入的 HTML 和貼上的文字，新題目都會放到：

匯入題目 HTML / 查詢解答

在練習頁面或修練結果頁按 Ctrl+S 存成 HTML，再拖曳到下方（可一次多個檔案，兩種一起拖進來也可以）。

  • 練習頁：記錄題目與選項，並列出已記錄的解答（字母對應該份檔案的選項順序）
  • 結果頁：自動補上（或更正）題庫的正確答案
  • 防偽驗證題會自動略過

貼上文字題庫（NotebookLM / 成績頁）

每題的格式：題目：…　正確答案：…（「你的答案」「得分」有沒有都可以）。 題庫裡已有同樣題目的選擇題，會直接補上解答；沒有的先存成答案紀錄（選項未知），之後匯入 HTML 時再依題目自動對應到選項。

GitHub 同步

題庫存放在 GitHub 儲存庫的 data/questions.json。 在這台電腦填入 Token 後，新增 / 修改題目會自動上傳，其他電腦打開網站就能看到。 Token 只會存在這台電腦的瀏覽器裡，不會上傳。請只在自己的電腦上填 Token。
