# 線性時間排序：決策樹、計數排序、基數排序、桶排序

## 1. 比較排序的下界：決策樹模型

- **比較排序**：排序結果只靠「元素之間的比較」決定（合併、堆積、快速、插入排序都是）。
- **決策樹模型（decision tree model）**：把某個比較排序在大小 n 的輸入上的行為畫成一棵二元樹
  - 每個**內部節點**是一次比較 aᵢ : aⱼ，每個**分支**是比較的結果（≤ 走左、> 走右）
  - 每個**葉節點**代表一種可能的**排列（排序結果）**
  - 從根到葉的路徑 = 一次執行；**樹的高度 = 最差情況的比較次數**
- **定理**：任何比較排序在最壞情況下需要 **Ω(n lg n)** 次比較。
  - 證明：要能排出所有輸入，葉節點至少 **n!** 個；高度 h 的二元樹最多 2ʰ 個葉 → 2ʰ ≥ n! → h ≥ lg(n!) = **Ω(n lg n)**
- 推論：**合併排序、堆積排序是漸進最佳的比較排序**；決策樹模型證明的是**比較排序的極限**。
- 要打破 Ω(n lg n)，就必須**不靠比較**、利用資料本身的性質——就是本章三種線性時間排序。

> 💡 填空寫法：`big-omega(nlogn)`；葉節點數量至少 `n!`。

> 相關題目：決策樹, decision tree, 葉節點, n!, 樹的高度, 下界, lower bound, 比較排序, 最優性, 最佳, 極限, big-omega(nlogn), comparison-based

## 2. 計數排序（Counting Sort）

- 前提：輸入是**整數**，範圍 0..k（或 1..k）。
- 想法：對每個 x 算出「≤ x 的元素有幾個」，就知道 x 該放的位置。
- 需要兩個輔助陣列：**C**（計數，大小 k+1）和 **B**（輸出，大小 n）。

```
COUNTING-SORT(A, B, k)
1  for i ← 0 to k               ▷ 課本投影片寫 1 to k
2      do C[i] ← 0
3  for j ← 1 to length[A]
4      do C[A[j]] ← C[A[j]] + 1   ▷ C[i] = 等於 i 的個數
5  for i ← 1 to k
6      do C[i] ← C[i] + C[i−1]    ▷ C[i] = 小於或等於 i 的個數
7  for j ← length[A] downto 1     ▷ 由後往前 → 穩定
8      do B[C[A[j]]] ← A[j]
9         C[A[j]] ← C[A[j]] − 1
```

（題庫的課本版本把第 9 行算成「for j ← length[A] downto 1」那一行，以下沿用題庫的行號說法。）

- 時間：**Θ(n + k)**；當 **k = O(n)** 時是 **Θ(n)**。空間主要取決於 **k**。
- **穩定（stable）**：相同的值在輸出中保持原本的相對順序——因為最後一個迴圈**由後往前**放。這是它能當基數排序子程序的原因。
- 不適合：**k 極大**、**鍵值是浮點數**、**記憶體非常有限**。

**追蹤範例**：A = [2, 5, 3, 0, 2, 3, 0, 3]，k = 5

- 計數後 C = [2, 0, 2, 3, 0, 1] → 累加後 **C = [2, 2, 4, 7, 7, 8]**（「做到第 9 行前」：B 全是 0）

| 處理 j | A[j] | 放到 | B（– 表示還空著） | C |
|---|---|---|---|---|
| 8 | 3 | B[7] | –, –, –, –, –, –, 3, – | 2, 2, 4, 6, 7, 8 |
| 7 | 0 | B[2] | –, 0, –, –, –, –, 3, – | 1, 2, 4, 6, 7, 8 |
| 6 | 3 | B[6] | –, 0, –, –, –, 3, 3, – | 1, 2, 4, 5, 7, 8 |
| 5 | 2 | B[4] | –, 0, –, 2, –, 3, 3, – | 1, 2, 3, 5, 7, 8 |
| 4 | 0 | B[1] | 0, 0, –, 2, –, 3, 3, – | 0, 2, 3, 5, 7, 8 |
| 3 | 3 | B[5] | 0, 0, –, 2, 3, 3, 3, – | 0, 2, 3, 4, 7, 8 |
| 2 | 5 | B[8] | 0, 0, –, 2, 3, 3, 3, 5 | 0, 2, 3, 4, 7, 7 |
| 1 | 2 | B[3] | 0, 0, 2, 2, 3, 3, 3, 5 | 0, 2, 2, 4, 7, 7 |

## 3. 基數排序（Radix Sort）

```
RADIX-SORT(A, d)
1  for i ← 1 to d
2      do use a stable sort to sort array A on digit i
```

- 從**最低有效位（LSD, least significant digit）**開始，一位一位排；每一位必須用**穩定排序**（通常用計數排序；插入排序、合併排序也穩定，**快速排序不行**）。
- 用來排**多位數鍵值**（例如日期的年、月、日）。
- **Lemma 8.3**：n 個 d 位數、每位有 k 種可能時，RADIX-SORT 能在 **Θ(d(n + k))** 時間內排好（每一位用計數排序）；d 是常數且 k = O(n) 時為線性。
- 基數排序**不是原地排序**：輸出要用額外的陣列。原地指的是只有常數個元素會存到陣列外。
- **Lemma 8.4：b 位元數字、每次處理 r 位元**（r 是每次處理的**位數區段長度**，r ≤ b）：共 d = ⌈b/r⌉ 回合，每回合 k = 2ʳ → **Θ((b/r)(n + 2ʳ))**；r 的選擇會影響**執行時間與空間**。
  - b < lg n 時取 r = b，得 Θ(n)
  - b ≥ lg n 時取 r = ⌊lg n⌋，得 **Θ(bn/lg n)**

**追蹤範例**：329, 457, 657, 839, 436, 720, 355（課本圖 8.3）

| 做完 | A |
|---|---|
| i = 1（個位） | 720, 355, 436, 457, 657, 329, 839 |
| i = 2（十位） | 720, 329, 436, 839, 355, 457, 657 |
| i = 3（百位） | 329, 355, 436, 457, 657, 720, 839 |

## 4. 桶排序（Bucket Sort）

- 前提：輸入**均勻分佈（uniform distribution）**在 [0, 1)。
- 作法：把 [0, 1) 切成 n 個大小相同的桶 → 每個數放進 **B[⌊n·A[i]⌋]** → 各桶用**插入排序**排好 → 依序**串接**。

```
BUCKET-SORT(A)
1  n ← length[A]
2  for i ← 1 to n
3      do insert A[i] into list B[⌊nA[i]⌋]
4  for i ← 0 to n − 1
5      do sort list B[i] with insertion sort
6  concatenate B[0], B[1], …, B[n−1] together in order
```

- **期望（平均）時間 Θ(n)**：均勻分佈下每個桶平均只有常數個元素。
- 資料**嚴重傾斜**（全擠在少數桶）時退化成插入排序的 **O(n²)**。效能取決於**資料分佈、桶的數量、桶內排序法**。

**追蹤範例**：A = 0.78, 0.17, 0.39, 0.26, 0.72, 0.94, 0.21, 0.12, 0.23, 0.68（n = 10）

| 桶 | 第 2–3 行插入完（依插入順序） | 第 4–5 行排好之後 |
|---|---|---|
| B[1] | 0.17, 0.12 | 0.12, 0.17 |
| B[2] | 0.26, 0.21, 0.23 | 0.21, 0.23, 0.26 |
| B[3] | 0.39 | 0.39 |
| B[6] | 0.68 | 0.68 |
| B[7] | 0.78, 0.72 | 0.72, 0.78 |
| B[9] | 0.94 | 0.94 |

> ⚠️ **題庫的計分慣例**（用程式模擬比對過）：
> - 「**第 2 行做到 i = N**」= A[1..N] **都已插入**（插在串列尾端），例：i = 5 時 B[1] = 0.17、B[2] = 0.26、B[7] = 0.78, 0.72
> - 「**第 4 行做到 i = N**」= B[0..N−1] 已排好、**B[N] 還沒排**，例：i = 7 時 B[7] 仍是 0.78, 0.72

## 5. 線性時間排序總整理

| | 計數排序 | 基數排序 | 桶排序 |
|---|---|---|---|
| 假設 | 整數、範圍 0..k | d 位數，每位範圍 k | [0,1) 均勻分佈 |
| 時間 | Θ(n + k) | Θ(d(n + k)) | 平均 Θ(n)、最壞 O(n²) |
| 穩定 | ✔ | ✔（子排序須穩定） | 視桶內排序 |
| 原地 | ✘ | ✘ | ✘ |

- 共通點：**不使用比較模型**、**需要對輸入做額外假設**、**用空間換時間**、不適用於任意物件；**不是永遠比比較排序快**。
- **快速排序不是**線性時間排序。

> 相關題目：線性時間, linear, 共通限制, 共有, 非比較, 空間換取時間, 不是線性時間, 複雜度的敘述

## 6. 桶排序的期望時間證明（課本 8.4）

- 令 nᵢ = 桶 B[i] 的元素個數。插入排序是平方時間，所以

T(n) = Θ(n) + Σ{i=0..n−1} O(nᵢ²)

- 取期望值，利用期望值的線性：

E[T(n)] = Θ(n) + Σ{i=0..n−1} O(E[nᵢ²])

- **要證 E[nᵢ²] = 2 − 1/n**。
- 令 Xᵢⱼ = I{A[j] 落在桶 i}，則 nᵢ = Σ{j=1..n} Xᵢⱼ，展開平方：

E[nᵢ²] = Σⱼ E[Xᵢⱼ²] + Σⱼ Σ{k≠j} E[Xᵢⱼ Xᵢₖ]

- 每個元素落在桶 i 的機率是 1/n：
  - E[Xᵢⱼ²] = 1² · (1/n) + 0² · (1 − 1/n) = **1/n**
  - k ≠ j 時兩者獨立，E[Xᵢⱼ Xᵢₖ] = (1/n)(1/n) = **1/n²**
- 代回去：

E[nᵢ²] = n · (1/n) + n(n − 1) · (1/n²) = 1 + (n − 1)/n = **2 − 1/n**

- 結論：E[T(n)] = Θ(n) + n · O(2 − 1/n) = **Θ(n)**。

**另一種算法**（用基本機率）

- nᵢ 是二項分佈，p = 1/n：E[nᵢ] = np = 1，Var[nᵢ] = np(1 − p) = 1 − 1/n
- E[nᵢ²] = Var[nᵢ] + E[nᵢ]² = 1 − 1/n + 1 = 2 − 1/n = Θ(1)
- 所以 Σ O(E[nᵢ²]) = O(n)
