# 快速排序（Quicksort）

## 1. 快速排序的概念

- 設計策略：**分治法（divide and conquer）**，三步驟：
  1. **Divide（分割）**：用 PARTITION 把 A[p..r] 分成 A[p..q−1] 和 A[q+1..r]，左邊每個元素 ≤ A[q]，右邊每個元素 > A[q]（A[q] 就是 pivot，已經在最終位置）
  2. **Conquer（征服）**：**遞迴**排序左右兩個子陣列
  3. **Combine（合併）**：**什麼都不用做**——子陣列已經原地排好
- **原地排序（in place）**：在輸入陣列本身運算、不需要複製陣列；**不穩定**。
- 雖然最壞情況 Θ(n²)，但**平均 Θ(n lg n) 且常數因子小**，所以實務上常比其他 O(n lg n) 演算法快；適合**大**陣列。

```
QUICKSORT(A, p, r)
1  if p < r
2      then q ← PARTITION(A, p, r)
3           QUICKSORT(A, p, q − 1)
4           QUICKSORT(A, q + 1, r)
```

- p 是起始索引、r 是結束索引；**p < r 才做 partition**（只剩 0 或 1 個元素就是基底情況）。
- 遞迴順序：先排 p..q−1，再排 q+1..r（**不包含 q 本身**）。最外層呼叫 QUICKSORT(A, 1, length[A])。

> ⚠️ 題庫的慣例：「快速排序的關鍵步驟」答 Divide、Conquer、Combine 三個；但「遞迴呼叫中**不包含**哪個部分」答**合併（Combine）**——因為 combine 這一步不需要額外動作。

> 相關題目：分治, divide, conquer, combine, 征服, 合併, 關鍵步驟, 原地, in-place, Quicksort(A, p, r), 遞迴呼叫, 主要策略, 設計策略, 主要差別, 特徵, recursively, 適用於

## 2. PARTITION（課本版本，Lomuto）

```
PARTITION(A, p, r)
1  x ← A[r]                 ▷ pivot 是最後一個元素
2  i ← p − 1
3  for j ← p to r − 1
4      do if A[j] ≤ x
5          then i ← i + 1
6               exchange A[i] ↔ A[j]
7  exchange A[i + 1] ↔ A[r]  ▷ pivot 歸位
8  return i + 1             ▷ 回傳 pivot 的索引 q
```

- 變數：**x 是 pivot**；**i** 標記「≤ pivot 區域」的右邊界；**j** 由左往右**掃描**陣列。
- 迴圈不變量：A[p..i] ≤ x、A[i+1..j−1] > x、A[r] = x、A[j..r−1] 尚未處理。
- 執行完後：左側都 ≤ pivot、右側都 > pivot、pivot 位於 q；**左右子陣列本身還沒排好**。
- 時間 Θ(n)（n = r − p + 1），只用常數額外空間。
- exchange 的用途：把較小的元素換到左區、最後把 pivot 換到正確位置。

**追蹤範例 1**：A = [2, 8, 7, 1, 3, 5, 6, 4]，pivot x = 4（課本圖 7.1）

| 步驟 | 動作 | 陣列 |
|---|---|---|
| 開始 | i = 0 | 2, 8, 7, 1, 3, 5, 6, 4 |
| j = 1 | 2 ≤ 4：i → 1，A[1]↔A[1] | 2, 8, 7, 1, 3, 5, 6, 4 |
| j = 2 | 8 > 4：不動 | 2, 8, 7, 1, 3, 5, 6, 4 |
| j = 3 | 7 > 4：不動 | 2, 8, 7, 1, 3, 5, 6, 4 |
| j = 4 | 1 ≤ 4：i → 2，A[2]↔A[4] | 2, **1**, 7, **8**, 3, 5, 6, 4 |
| j = 5 | 3 ≤ 4：i → 3，A[3]↔A[5] | 2, 1, **3**, 8, **7**, 5, 6, 4 |
| j = 6、7 | 5、6 > 4：不動 | 2, 1, 3, 8, 7, 5, 6, 4 |
| 最後 | A[4]↔A[8]，回傳 q = 4 | 2, 1, 3, **4**, 7, 5, 6, **8** |

- 「當 j 指向 3 時」（還沒處理 j = 5）陣列是 **2, 1, 7, 8, 3, 5, 6, 4**；最後 pivot 在**第 4 個位置**。

**追蹤範例 2**：A = [3, 2, 9, 8, 1, 7, 6, 5]，pivot x = 5

| 步驟 | 動作 | 陣列 |
|---|---|---|
| j = 1、2 | 3、2 ≤ 5：i 依序到 2（自己和自己交換） | 3, 2, 9, 8, 1, 7, 6, 5 |
| j = 3、4 | 9、8 > 5：不動 | 3, 2, 9, 8, 1, 7, 6, 5 |
| j = 5 | 1 ≤ 5：i → 3，A[3]↔A[5] | 3, 2, **1**, 8, **9**, 7, 6, 5 |
| j = 6、7 | 7、6 > 5：不動 | 3, 2, 1, 8, 9, 7, 6, 5 |
| 最後 | A[4]↔A[8]，q = 4 | 3, 2, 1, **5**, 9, 7, 6, **8** |

- 「當 j 移動到指向元素 1 的當下」（交換前）陣列還是 **3, 2, 9, 8, 1, 7, 6, 5**。

**變化題：改用第一個元素 A[p] 當 pivot**

```
PARTITION(A, p, r)
1  x ← A[p]
2  i ← p
3  for j ← p + 1 to r
4      do if A[j] ≤ x
5          then i ← i + 1
6               exchange A[i] ↔ A[j]
7  exchange A[p] ↔ A[i]     ▷ pivot 換到 i
8  return i
```

> 💡 填空寫法：`exchange(A[p],A[i])`、`returni`（不留空白）。

## 3. 效能分析

| 情況 | 分割方式 | 遞迴式 | 結果 |
|---|---|---|---|
| **最壞** | 每次 n−1 和 0 | T(n) = T(n−1) + Θ(n) | **Θ(n²)** |
| **最好** | 每次對半 | T(n) = 2T(n/2) + Θ(n) | **Θ(n lg n)** |
| **平衡（例 9:1）** | 每次 9n/10 和 n/10 | T(n) = T(9n/10) + T(n/10) + Θ(n) | **O(n lg n)** |

- **最壞情況何時發生**：**輸入已排序**或**反向排序**（用最後一個元素當 pivot 時，pivot 每次都是最大或最小值）、所有元素都相同；本質上就是**pivot 選擇不當、分割嚴重不平均**。
- **9:1 的遞迴樹**：每層代價最多 cn；
  - 較短的一邊（一直走 n/10）高度 **log₁₀ n**
  - 較長的一邊（一直走 9n/10）高度 **log₁₀/₉ n**
  - 所以總共 O(n lg n)——**只要分割比例是常數，就是 O(n lg n)**
- 平均情況：好壞分割交錯出現時，壞分割的代價會被吸收，仍是 O(n lg n)。
- **空間**：主要是**遞迴堆疊的深度**——理想情況 O(lg n)，最壞情況 O(n)；另外只有交換用的暫存變數。
- 小陣列時，快速排序可能比插入排序慢：**遞迴呼叫的額外開銷**。

> 💡 填空寫法：`log_(10)(n)`、`log_(10/9)(n)`。
> ⚠️ 題庫的慣例：「快速排序在 ＿＿ 情況下表現最好」答 **average**；「空間複雜度」答 **O(logn)**（課本會說最壞情況 O(n)）。

> 相關題目：最差情況, 最壞情況, worst, O(n²), O(n^2), 已排序, 反向, 不平均, 9n/10, 較高, 較低, 高度, 遞迴樹深度, 平均, average, 最好, 空間複雜度, space, 遞迴堆疊, 小陣列, 額外開銷, Worst-case partition, average-case, 變慢, 時間複雜度

## 4. 隨機化快速排序與改進

- **RANDOMIZED-PARTITION**：先在 A[p..r] 中**隨機選一個元素和 A[r] 交換**，再呼叫一般的 PARTITION。
- 目的：讓分割的好壞**不再取決於輸入的排列**，避免最差情況頻繁發生；**期望執行時間 Θ(n lg n)**。
- 其他改進：**三數取中法（median-of-three）**選 pivot、**子問題很小時改用插入排序**。
- 要維持好效能的關鍵：**均勻的分割**、隨機選 pivot、正確的遞迴處理。
- 可以處理**重複元素**（但全部相同時，課本版本會退化成 Θ(n²)）。

**快速排序 vs. 其他排序**

| 比較 | 快速排序 | 合併排序 | 堆積排序 |
|---|---|---|---|
| 最壞 | Θ(n²) | Θ(n lg n) | O(n lg n) |
| 平均 | Θ(n lg n)，**常數小，通常最快** | Θ(n lg n) | O(n lg n) |
| 原地 | ✔ | ✘（主要差別） | ✔ |
| 穩定 | ✘ | ✔ | ✘ |
