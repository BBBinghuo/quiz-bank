# 中位數與順序統計量

## 1. 順序統計量與選擇問題

- **第 i 個順序統計量（ith order statistic）**：n 個元素中**第 i 小**的元素。
  - i = 1 是最小值，i = n 是最大值
  - **中位數（median）**：中間的那一個，約第 n/2 個順序統計量
  - n 是偶數時有兩個中位數：第 n/2 個（下中位數）和第 n/2 + 1 個（上中位數），也有人定義成兩者的平均
- **選擇問題（selection problem）**：
  - 輸入：一組 n 個（各不相同的）數字，和一個數字 i（1 ≤ i ≤ n）
  - 輸出：恰好比其他 i − 1 個元素大的那個元素 x
- 最直接的做法是先排序再取第 i 個，要 O(n lg n)。本章的目標是做到 **O(n)**，不必整個排序。
- 應用：四分位數、中位數分析、排程的優先級。

> 💡 填空寫法：中位數是第 `n/2` 個順序統計量；題庫假設元素是 `distinct`（各不相同）。

> 相關題目：順序統計量, order statistic, 選擇問題, Selection Problem, 中位數, Median, 排名, 四分位數, 偶數, distinct, 順序統計量與排序, n=1

## 2. 最小值與最大值

```
MINIMUM(A)
1  min ← A[1]
2  for i ← 2 to length[A]
3      do if min > A[i]
4          then min ← A[i]
5  return min
```

- 比較 **n − 1** 次，時間 **O(n)**；這也是下界，因為其他 n − 1 個元素每個都至少要輸一次。
- 第 4 行的期望執行次數是 **O(lg n)**（隨機排列下，新的最小值不常出現）。

**同時找最大值和最小值**

| 做法 | 比較次數 |
|---|---|
| 分開找：最大值 n − 1 次、最小值 n − 1 次 | **2n − 2** |
| 配對比較：每 2 個元素花 3 次 | **約 3n/2**（精確是 ⌈3n/2⌉ − 2） |

- 配對比較的作法：把元素分成 n/2 對，每對先比一次，**小的再和 min 比、大的再和 max 比**。
- 初始化：n 是奇數時 min、max 都設成 A[1]，從第 2 個開始配對；n 是偶數時先比 A[1]、A[2]，從第 3 個開始。

**第二小的元素**

- 最壞情況要 **n + ⌈lg n⌉ − 2** 次比較。
- 錦標賽法：兩兩比賽找出最小值，花 n − 1 次。第二小一定曾經輸給最小值，而最小值最多比過 ⌈lg n⌉ 場，再從這些對手裡挑最小，花 ⌈lg n⌉ − 1 次。

> 相關題目：最小值, Minimum, 最大值, Maximum, 配對比較, 3n/2, 1.5n, 2n-2, n-1, GET_MIN_MAX, 第二小, Second smallest, 候選, 同時尋找, 同時找出, 兩兩比較

## 3. 期望線性時間的選擇：Randomized-Select

```
RANDOMIZED-SELECT(A, p, r, i)
1  if p = r
2      then return A[p]
3  q ← RANDOMIZED-PARTITION(A, p, r)
4  k ← q − p + 1
5  if i = k            ▷ pivot 就是答案
6      then return A[q]
7  elseif i < k
8      then return RANDOMIZED-SELECT(A, p, q − 1, i)
9  else return RANDOMIZED-SELECT(A, q + 1, r, i − k)
```

- 想法：和快速排序一樣用 Partition 分割，但**只遞迴進答案所在的那一邊**。
- k 是 pivot 在這一段的排名：
  - i = k：pivot 就是答案
  - i < k：答案在左邊，i 不變
  - i > k：答案在右邊，左邊和 pivot 共 k 個已經排除，所以改找第 **i − k** 小
- 時間：**平均 O(n)**，最壞 **O(n²)**（每次都選到最大或最小值）。
- 優點：平均快、實作簡單、原地，不需要額外空間。

| | Quicksort | Randomized-Select |
|---|---|---|
| 分割 | Partition | Partition |
| 遞迴 | 兩邊都遞迴 | **只遞迴一邊** |
| 平均 | O(n lg n) | **O(n)** |
| 最壞 | O(n²) | O(n²) |

> ⚠️ 依題庫的答案：「最壞情況的發生條件」也包含陣列幾乎已排序（課本 Partition 固定選最後一個時才會這樣，隨機選 pivot 的機率很低）；「在什麼情況下最快」填 **average**。

> 相關題目：Randomized-Select, RANDOMIZED_SELECT, Randomized-Partition, Partition, partition, pivot, Quicksort, 歸位, 平分, 平均時間複雜度, 最壞情況, 隨機

## 4. Randomized-Select 的期望時間分析

- 令 Xₖ = I{子陣列 A[p..q] 恰好有 k 個元素}，pivot 排名平均分佈，所以 **E[Xₖ] = 1/n**。
- 假設答案總是落在較大的那一邊（上界）：

T(n) ≤ Σ{k=1..n} Xₖ · T(max(k − 1, n − k)) + O(n)

- 取期望值。Xₖ 和 T(max(k − 1, n − k)) 獨立，可以拆開：

E[T(n)] ≤ (1/n) Σ{k=1..n} E[T(max(k − 1, n − k))] + O(n)

- k > ⌈n/2⌉ 時 max 是 k − 1，否則是 n − k，所以 ⌊n/2⌋ 到 n − 1 每一項最多出現兩次：

E[T(n)] ≤ (2/n) Σ{k=⌊n/2⌋..n−1} E[T(k)] + O(n)

- 用代入法，**猜 E[T(n)] ≤ cn**，O(n) 項寫成 an：

```
E[T(n)] ≤ (2/n) Σ{k=⌊n/2⌋..n−1} ck + an
        ≤ c(3n/4 + 1/2) + an
        = cn − (cn/4 − c/2 − an)
```

- 要讓結果 ≤ cn，需要 cn/4 − c/2 − an ≥ 0。
- 選 c > 4a，兩邊除以 (c/4 − a)，得 n ≥ 2c/(c − 4a)。
- 比這更小的 n 當成 O(1)，就得到 **E[T(n)] = O(n)**。

**另一種寫法**（投影片的第二種分析）

- 用平均情況的遞迴式：T(n) ≤ (1/n)(T(n − 1) + 2 Σ{k=⌈n/2⌉..n−1} T(k)) + O(n) ≤ (2/n) Σ T(k) + O(n)
- 猜 T(n) ≤ cn，得 T(n) ≤ c(3n/4 + 1/2) + O(n) ≤ cn；c 取夠大，讓 c(n/4 − 1/2) 蓋過 O(n) 項。

> 💡 直覺：每次平均丟掉一部分元素，成本是等比級數 n + n/2 + n/4 + … ≤ 2n，所以是線性。

> 相關題目：平均, 平分, O(n), average

## 5. 最壞情況線性時間：Select（中位數的中位數）

SELECT 用**保證品質的 pivot**，克服最壞 O(n²)：

1. 把 n 個元素分成 ⌊n/5⌋ 組、每組 5 個，剩下的 n mod 5 個自成一組
2. 每組用插入排序，找出各組中位數，共 ⌈n/5⌉ 個
3. **遞迴呼叫 SELECT**，找出這些中位數的中位數 x
4. 以 x 為 pivot 做修改版的 Partition，令 k 是低側的元素個數加 1（x 是第 k 小）
5. i = k 就回傳 x；i < k 遞迴低側；i > k 在高側遞迴找第 i − k 小

**為什麼能保證分割品質**

- ⌈n/5⌉ 個中位數裡，至少一半 ≥ x。
- 這些組每組至少有 3 個元素比 x 大；扣掉 x 自己那組和不滿 5 個的尾巴，少算 2 組：

比 x 大的元素 ≥ 3(⌈(1/2)⌈n/5⌉⌉ − 2) ≥ **3n/10 − 6**

- 同理，比 x 小的也至少 3n/10 − 6 個，所以遞迴最多處理 **7n/10 + 6** 個元素。

**遞迴式**

T(n) = O(1)，n ≤ 140

T(n) ≤ T(⌈n/5⌉) + T(7n/10 + 6) + O(n)，n > 140

- 三項分別是：找中位數的中位數、遞迴較大的一邊、分組與分割。
- 猜 T(n) ≤ cn：

```
T(n) ≤ c⌈n/5⌉ + c(7n/10 + 6) + an
     ≤ cn/5 + c + 7cn/10 + 6c + an
     = 9cn/10 + 7c + an
     = cn + (−cn/10 + 7c + an)
```

- c 取夠大，讓 c(n/10 − 7) ≥ an（n > 140），就得到 **T(n) = O(n)**。
- **應用**：用 SELECT 找中位數當 pivot，QUICKSORT 的最壞情況也能改善成 **O(n lg n)**。
- 實務上常數較大，通常沒有 Randomized-Select 快；優點是穩定、對輸入不敏感、保證線性。

> ⚠️ 題庫 2515–2517 的「中位數選擇法」，題庫答案的 pivot 是 63（或 59）。照本節 5 個一組算，各組中位數是 42、63、50、37，中位數的中位數應是 42 或 50，算不出 63；題目文字也沒寫要找第幾小。原題可能另有條件，請對照原題。

> 💡 填空寫法：分成 `five` 組；遞迴式的兩格是 `T(7n/10+6)` 和 `O(n)`。
