# 演算法基礎、插入排序、合併排序與漸進符號

## 1. 演算法是什麼

- **演算法**：一個定義清楚的計算程序，接收輸入、產生輸出；也可以看成「解決某個明確計算問題的工具」。
- **問題實例（instance）**：計算一個答案所需的全部輸入。
- **正確的演算法**：對**每一個**輸入實例都會**停止**，而且輸出正確答案。不正確的演算法可能永遠不停，或停下來但答案錯。
- 以排序為例：輸入 n 個數 ⟨a₁…aₙ⟩，輸出一個排列 ⟨a′₁…a′ₙ⟩，使 a′₁ ≤ a′₂ ≤ … ≤ a′ₙ；被排序的數稱為 **key**。

> 相關題目：instance, 實例, 正確的演算法, correct, 計算程序, 定義清楚

## 2. 插入排序（Insertion Sort）

- 設計方法：**增量法（incremental approach）**——每次把一個新元素插進「已排好的前半段」。
- **原地排序（sorted in place）**：只在陣列內重排，任何時刻陣列外最多只放常數個元素。

```
Insertion-Sort(A)
1 for j ← 2 to length[A]
2     do key ← A[j]
3        ▷ 把 A[j] 插入已排序的 A[1..j-1]
4        i ← j - 1
5        while i > 0 and A[i] > key
6            do A[i+1] ← A[i]
7               i ← i - 1
8        A[i+1] ← key
```

- **迴圈不變量（loop invariant）**：每次 for 迴圈（第 1–8 行）開始時，A[1..j-1] 由**原本就在 A[1..j-1] 的元素**組成，而且已排序。用它來證明演算法正確。
- 設 tⱼ = 第 5 行 while 判斷在某個 j 執行的次數：
  - **最佳情況**（輸入已排序）：tⱼ = 1 → 執行時間是 n 的**線性函數** → Θ(n)
  - **最壞情況**（輸入反向排序）：tⱼ = j → 執行時間是 n 的**二次函數** → Θ(n²)
  - 平均情況通常和最壞一樣糟（也是二次）

> 💡 **常考計算**：每行成本都算 1、第 5 行每次只執行 1 次（tⱼ = 1）。第 1 行 n 次，第 2、4、5、8 行各 n−1 次，第 3 行是註解（成本 0），第 6、7 行 0 次 → 總成本 n + 4(n−1) = **5n − 4**。

> 相關題目：插入排序, insertion, 迴圈不變量, loop invariant, 5n-4, 原地排序, in place

## 3. 分析演算法與「最壞情況」

- 分析演算法 = **預測它需要的資源**：記憶體、通訊頻寬、邏輯閘、時間（最常關心時間）。
- 模型假設：**單處理器 RAM 模型**——指令一條一條依序執行（沒有並行），每個基本指令花常數時間。
- 執行時間 = 某個輸入下執行的基本操作（step）數；step 盡量定義成和機器無關。
- 通常只看**最壞情況**，原因：
  1. 它是執行時間的**上界保證**
  2. 最壞情況其實**相當常發生**
  3. 平均情況常常和最壞**一樣糟**（例如插入排序）
- 真正在意的是執行時間的**成長率（order of growth）**。

> 相關題目：分析演算法, RAM, 最壞情況, worst-case, 資源

## 4. 合併排序（Merge Sort）與分治法

- **分治法（divide-and-conquer）** 三步：**divide**（分成子問題）→ **conquer**（遞迴解子問題）→ **combine**（合併子問題的解）。
- MERGE(A, p, q, r)：
  - 把兩段複製到輔助陣列 **L、R**，尾端各放一個 **∞ 哨兵（sentinel）**，就不用檢查哪邊先用完
  - 從 L、R 依序挑較小的放回 A[p..r]
  - 需要額外陣列 → **不是原地排序**
- MERGE-SORT(A, p, r)：若 p < r，取 q = ⌊(p+r)/2⌋，排左半、排右半，再 MERGE。
- 遞迴式：T(n) = 2T(n/2) + Θ(n)（n > 1），解為 **Θ(n lg n)**——當 n 夠大時勝過插入排序。

> 相關題目：合併排序, merge, 分治, divide, 哨兵, sentinel

## 5. 漸進符號

| 符號 | 意義 | 定義（存在正常數 c、n₀，對所有 n ≥ n₀） |
|---|---|---|
| Θ(g(n)) | 漸進**緊確**界 | c₁g(n) ≤ f(n) ≤ c₂g(n) |
| O(g(n)) | 漸進**上**界 | 0 ≤ f(n) ≤ c·g(n) |
| Ω(g(n)) | 漸進**下**界 | 0 ≤ c·g(n) ≤ f(n) |
| o(g(n)) | **非緊確**上界 | 對**所有** c > 0 都成立 f(n) < c·g(n)；lim f/g = 0 |
| ω(g(n)) | **非緊確**下界 | 對**所有** c > 0 都成立 c·g(n) < f(n)；lim f/g = ∞ |

- **定理 3.1**：f(n) = Θ(g(n)) ⇔ f(n) = O(g(n)) **且** f(n) = Ω(g(n))。
- 多項式 p(n) = Σ aᵢnⁱ（a_d > 0）→ p(n) = Θ(n^d)。
- 可以類比成實數比大小：O ≈ ≤、Ω ≈ ≥、Θ ≈ =、o ≈ <、ω ≈ >。

| 性質 | 哪些符號成立 |
|---|---|
| 遞移性 Transitivity | Θ、O、Ω、o、ω 全部 |
| 反身性 Reflexivity | Θ、O、Ω（o、ω 不行） |
| 對稱性 Symmetry | **只有 Θ**：f = Θ(g) ⇔ g = Θ(f) |
| 轉置對稱 Transpose symmetry | f = O(g) ⇔ g = Ω(f)；f = o(g) ⇔ g = ω(f) |

> ⚠️ **易錯**：「f = O(g) ⇔ g = O(f)」是**錯的**（對稱性只有 Θ 有）。實數有三一律，函數**沒有**——例如 n 和 n^(1+sin n) 無法比較。

> 💡 填空題的寫法：題目要求用 `big-theta`、`big-omega`、`theta`、`omega`、`O`、`o`，log 不可寫成 lg，上標用 `^`，例如 `big-theta(nlogn)`、`big-omega(f(n))`。

> 相關題目：漸進, asymptotic, Θ, big-theta, big-omega, 上界, 下界, 緊確, 對稱, 遞移, transitivity, symmetry

## 6. 常見函數與數學工具

**單調性**（注意 ≤ 和 < 的差別）

| 名稱 | 條件 |
|---|---|
| 單調遞增 monotonically increasing | m ≤ n ⇒ f(m) ≤ f(n) |
| 單調遞減 monotonically decreasing | m ≤ n ⇒ f(m) ≥ f(n) |
| 嚴格遞增 strictly increasing | m < n ⇒ f(m) < f(n) |
| 嚴格遞減 strictly decreasing | m < n ⇒ f(m) > f(n) |

**地板與天花板**

- ⌊x⌋：小於等於 x 的最大整數（floor）；⌈x⌉：大於等於 x 的最小整數（ceiling，題目中譯「高斯函數」）
- x − 1 < ⌊x⌋ ≤ x ≤ ⌈x⌉ < x + 1
- 整數 n：⌈n/2⌉ + ⌊n/2⌋ = n
- ⌊⌊n/a⌋/b⌋ = ⌊n/ab⌋、⌈⌈n/a⌉/b⌉ = ⌈n/ab⌉

**模運算**：a mod n = a − ⌊a/n⌋·n（餘數）；若 a mod n = b mod n，寫成 a ≡ b (mod n)。

**多項式與指數**

- **多項式有界**：f(n) = n^O(1)，也就是 f(n) = O(n^k)
- 對 a > 1：n^b = o(aⁿ)，lim n^b / aⁿ = **0** → 任何正指數函數長得比任何多項式快
- 1 + x ≤ eˣ；|x| ≤ 1 時 eˣ ≤ 1 + x + x²；lim (1 + x/n)ⁿ = eˣ
  - 題庫有選項寫成「eˣ ≤ 1 + x + x²/2」並當成正確；課本（CLRS）的寫法是 x²，而且 x > 0 時 x²/2 的版本其實不成立。作答時以題庫解答為準，但要知道課本原式。

**對數**

- 沒特別說明時 **lg n = log₂ n**
- x > −1 時：x/(1+x) ≤ ln(1+x) ≤ x；|x| < 1 時 ln(1+x) = x − x²/2 + x³/3 − …
- **多對數有界（polylogarithmically bounded）**：f(n) = O(lg^k n)，例如 lg²n、(lg n)⁵、lg lg n
- lg^b n = o(n^a)（a > 0）→ 任何正多項式長得比任何多對數函數快

**階乘（史特林近似 Stirling's approximation）**

- n! = √(2πn)·(n/e)ⁿ·(1 + Θ(1/n))，用來估計**階乘**的成長
- n! = o(nⁿ)、n! = ω(2ⁿ)、**lg(n!) = Θ(n lg n)**

**重複對數 lg\* n**（iterated logarithm）：把 lg 一直套用直到結果 ≤ 1 的次數。成長極慢。

| n | 2 | 4 | 16 | 65536 | 2^65536 |
|---|---|---|---|---|---|
| lg\* n | 1 | 2 | 3 | 4 | 5 |

可觀測宇宙的原子數約 10⁸⁰，遠小於 2^65536，所以幾乎遇不到 lg\* n > 5。

**費氏數列**：F₀ = 0、F₁ = 1、Fᵢ = Fᵢ₋₁ + Fᵢ₋₂（i ≥ 2）；Fᵢ = (φⁱ − φ̂ⁱ)/√5，黃金比例 **φ ≈ 1.618**、φ̂ ≈ −0.618；Fᵢ 以指數成長。
